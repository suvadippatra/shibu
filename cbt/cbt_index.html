❓ CBT Setter Guide

Welcome to the Question Paper Setter!

This tool allows you to visually construct professional computer-based tests and export them as standalone, offline-capable exam files.

1. Question Types (MCQ vs NAT)

Use the dropdown on each question block to select its type. If you choose NAT, the multiple-choice options will vanish, and you can provide an exact value or an acceptable range (e.g., "2.5-3.5") as the correct answer. NATs do not deduct negative marks.

2. Formatting Text & Options

  • Bold Text: Wrap text in double asterisks like **this** to emphasize words. Do not use HTML tags.
  • Images: Click the 🖼️ button on the main question OR next to any Option. The built-in Cropper lets you compress images drastically and apply Black & White scanner filters to save space.
  • Tables: Click the 📊 button to draw a responsive grid inside a question. Click Edit later to change its contents.

3. Previewing the Exam

The right panel displays a live preview of the current section. Select a tab at the top of the preview panel to view all questions exactly as the student will see them. The preview updates instantly as you type.

4. Generating Final Output

Once ready, click the large 🚀 Compile button at the bottom left. This merges your questions, rules, images, and audio into a single HTML exam file. You can also use the "Import/Export CBT" button to save your raw work-in-progress data to continue editing later.
