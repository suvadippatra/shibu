❓ CBT Setter Guide / নির্দেশিকা

How to Use (English)

  1. Click 🤖 AI Prompt and copy the strict text format for your subject type.
  2. Paste the prompt along with your Exam PDF into an AI (like Gemini 1.5 Pro or Flash).
  3. Copy the resulting `.CBT` text code generated by the AI.
  4. Click 📌 Import / Export in this app, paste the code, and click Import Data.
  5. If the AI encounters an un-extractable image, it will automatically create a 🚨 UPLOAD MISSING IMAGE button for you to quickly attach it.
  6. Images automatically lazy-load to save memory. Click 🖼️ View Attached Image to reveal them for 20 seconds.
  7. Use **bold text**, *italic text*, and __underline text__ directly in the question boxes to format your typography.
  8. Click 📌 Import / Export -> 🔄 Sync CBT Code to save a backup of your work!
  9. Click 🚀 Compile & Generate Final HTML to download your standalone, offline exam file.

কীভাবে ব্যবহার করবেন (বাংলা)

  1. 🤖 AI Prompt বাটনে ক্লিক করুন এবং আপনার বিষয়ের জন্য লেখাটি কপি করুন।
  2. কপি করা লেখাটি এবং আপনার পরীক্ষার PDF ফাইলটি একটি AI (যেমন Gemini 1.5 Pro) এ পেস্ট করুন।
  3. AI যে `.CBT` টেক্সট কোডটি তৈরি করবে, সেটি সম্পূর্ণ কপি করুন।
  4. এই অ্যাপের 📌 Import / Export বাটনে ক্লিক করে কোডটি পেস্ট করুন এবং Import Data চাপুন।
  5. AI যদি কোনো ছবি বা ডায়াগ্রাম পড়তে না পারে, তবে সেটি স্বয়ংক্রিয়ভাবে 🚨 UPLOAD MISSING IMAGE বাটন তৈরি করবে যাতে আপনি সহজে ছবি আপলোড করতে পারেন।
  6. মেমরি বাঁচাতে ছবিগুলো লুকানো থাকে। 🖼️ View Attached Image এ ক্লিক করলে তা ২০ সেকেন্ডের জন্য দেখা যাবে।
  7. লেখা বোল্ড বা ইটালিক করতে **bold** বা *italic* বা __underline__ ব্যবহার করুন।
  8. কাজ শেষে 📌 Import / Export -> 🔄 Sync CBT Code এ ক্লিক করে আপনার কাজের একটি ব্যাকআপ (CBT ফাইল) সেভ করে রাখুন!
  9. সবশেষে নিচে 🚀 Compile & Generate Final HTML বাটনে ক্লিক করে আপনার অফলাইন পরীক্ষার ফাইলটি ডাউনলোড করে নিন।
