❓ CBT Setter Guide

Advanced Features & Best Practices

  1. AI Prompt Injection: Click 🤖 Prompt, copy the text, and paste it into Gemini/GPT alongside your Exam PDF. Copy the resulting `.cbt` code and paste it into 📌 Import.
  2. Memory Protection (20s VRAM Flush): To prevent mobile browsers from crashing, images load as a `🖼️ View Image` button. When clicked, the image renders for 20 seconds before silently deleting itself from the GPU memory. You can reveal all images at once from the ⋮ menu.
  3. Typography: Use `**bold**`, `*italic*`, and `__underline__` directly in the text boxes. Scientific names (e.g. *Mangifera indica*) must be italicized using asterisks.
  4. Image Auto-Detection: If the AI cannot read a diagram, it will output `[IMAGE]`. Our system automatically detects this, deletes the text, and spawns a glowing red 🚨 UPLOAD MISSING IMAGE button for you.
  5. Mobile Resizer: On a tablet or phone, drag the thin `⋮` bar up and down to adjust the split-screen between the Editor and the Live Preview.
  6. Syncing & Compiling: Always click 📌 Import -> 🔄 Sync CBT Code to create a manual backup. When finished, click 🚀 Compile Final HTML to generate your fully standalone, offline exam file.

অ্যাডভান্সড ফিচার ও ব্যবহার নির্দেশিকা

  1. AI Prompt ব্যবহার: 🤖 Prompt বাটনে ক্লিক করে লেখাটি কপি করুন এবং Gemini/GPT-তে আপনার PDF ফাইলের সাথে পেস্ট করুন। AI যে `.cbt` কোডটি দেবে, তা 📌 Import এ পেস্ট করুন।
  2. মেমরি প্রোটেকশন (20s VRAM Flush): মোবাইল ব্রাউজার ক্র্যাশ এড়াতে ছবিগুলো সরাসরি লোড না হয়ে `🖼️ View Image` বাটন হিসেবে থাকে। ক্লিক করলে ২০ সেকেন্ডের জন্য ছবিটি দেখা যাবে এবং তারপর মেমরি বাঁচাতে নিজে থেকেই বন্ধ হয়ে যাবে।
  3. টাইপোগ্রাফি (Typography): লেখা বোল্ড বা ইটালিক করতে **bold**, *italic*, এবং __underline__ ব্যবহার করুন। বৈজ্ঞানিক নাম (যেমন *Mangifera indica*) অবশ্যই অ্যাস্টেরিস্ক দিয়ে ইটালিক করতে হবে।
  4. অটো-ইমেজ ডিটেকশন: AI যদি কোনো ডায়াগ্রাম পড়তে না পারে, তবে সে `[IMAGE]` লেখে। আমাদের সিস্টেম তা ধরে ফেলে এবং স্বয়ংক্রিয়ভাবে একটি লাল 🚨 UPLOAD MISSING IMAGE বাটন তৈরি করে দেয়।
  5. মোবাইল রিসাইজার (Mobile Resizer): মোবাইল বা ট্যাবলেটে `⋮` বারটি উপর-নিচ টেনে এডিটর এবং লাইভ প্রিভিউয়ের সাইজ নিজের মতো ঠিক করে নিন।
  6. সেভ এবং কম্পাইল (Sync & Compile): কাজ শেষে 📌 Import -> 🔄 Sync CBT Code এ ক্লিক করে ব্যাকআপ রাখুন। সবশেষে 🚀 Compile Final HTML এ ক্লিক করে আপনার অফলাইন পরীক্ষার ফাইলটি ডাউনলোড করুন।
