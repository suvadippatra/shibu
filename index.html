ℹ️ Quick Start Guide

1. Question Paper Maker (qp/index.html): Type Bengali or English questions, wrap LaTeX math in [EQ:...] or $...$, chemistry in [CHEM:2H2O], print Mono/Double/Quad/Booklet Flow PDFs, or export directly to .cbt.

2. CBT Builder (cbt/cbt_index.html): Import .cbt text, crop question diagrams, pick MathML / KaTeX Offline / HTML Fallback, and compile one portable *_Final.html exam file.

3. Quick Import: Drop any .qpf or .cbt file onto the hero dropzone to open it directly in the matching editor.

4. Offline PWA: Once loaded, core pages, fonts, KaTeX, and PDF-Lib are cached locally by the Service Worker for offline tablet use.
