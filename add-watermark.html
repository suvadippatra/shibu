How to Use

1. Select Target: Choose the PDF file you wish to protect.

2. Choose Type: Use the tabs to select between plain text, a custom image upload, or your pre-existing SVG logo.

3. Transform: Adjust the sliders to scale, rotate, and position the watermark. Position X and Y are percentages (e.g., 50% is dead center).

4. Apply & Preview: Click Apply. You can review the result in the frame below, make adjustments if needed, and hit Download when satisfied.
